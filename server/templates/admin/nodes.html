How it runs by itself

  • Customers add their MT5 on the website. The VPS copies MT5 for them and logs in; unknown broker servers are looked up automatically.
  • Crashed MT5s restart by themselves. After a reboot the VPS logs itself in and everything starts again.
  • Windows updates restart the VPS only on Saturday, when gold is closed.
  • Update the website in Admin → System and every VPS updates itself.
  • The bot tells you when a VPS goes offline, fills up, runs low on disk, or an account can't log in.
{% endif %}

Rough guide: each MT5 uses 150–250 MB of RAM. A 4 GB VPS handles about 10–12 accounts, an 8 GB VPS about 25, 12 GB about 35.

Brokers MT5 knows

MT5 needs to learn each broker once. When a customer's account says MT5 couldn't find their server and the name is right:

  1. On any VPS, double-click PipsFarmer - add a broker on the desktop.
  2. File → Open an Account, search the broker's name, then click Cancel.
  3. Close MT5. Every VPS learns the broker within a few minutes, and waiting accounts connect by themselves.
